# Bahaa Mall website

Static website for Bahaa Mall (needed for Meta Business Verification), served by GitHub Pages at https://bahaamall.store.

- Edit `config.json` (phone, WhatsApp, hours, photos, Meta verification code) and put photos in `src/img/`.
- Run `node build.mjs` — it writes the site into `docs/`.
- Commit and push; GitHub Pages publishes `docs/` automatically.
